# Models

`Models/` contains model-level theory notes, introductions, conventions, and exact-reference material that should not be tied to one project implementation.

Use this folder when a model explanation needs to be reused across projects or when a new paper introduces a model that should be understood before it becomes a project.

## Current Model Areas

| Path | Role |
|---|---|
| `1d-spin-chains/` | 1D spin-chain Hamiltonian families, conventions, and exact references |

## Boundary

- Keep project-specific implementation slices, scripts, and progress notes under `Projects/`.
- Keep reusable model definitions and exact-solution introductions here.
- A project may link to these notes, but should not duplicate the full model theory.
