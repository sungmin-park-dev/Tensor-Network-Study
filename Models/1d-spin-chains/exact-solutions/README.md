# Exact Solutions

This folder keeps exact-reference notes for reusable 1D spin-chain model theory.

## Current Files

| Path | Role |
|---|---|
| `method/README.md` | Index of exact-solution methods |
| `method/bethe-ansatz.md` | Bethe ansatz method and Heisenberg thermodynamic anchor |
| `method/jordan-wigner.md` | Jordan-Wigner transformation method |
| `method/free-fermion-diagonalization.md` | Number-conserving quadratic fermion diagonalization |
| `method/bogoliubov-diagonalization.md` | Quadratic fermion diagonalization with pairing |
| `xx-chain.md` | XX point finite-chain reference |
| `xxz-chain.md` | XXZ chain Bethe ansatz reference |
| `tfim-chain.md` | Transverse-field Ising limit reference |

## Boundary

- Keep method explanations and model-level exact references here.
- Keep project-specific benchmark choices, solver sets, and pass/fail tolerances in `Projects/`.
- Add a further model-specific note only when the reusable reference is ready to stand apart from a
  single project slice.
