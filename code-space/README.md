# code-space

`code-space/` contains shared code and toolbox components that are meant to be reused across TNS projects.

The current package skeleton lives in `src/`.

## Contents

| Path | Role |
|---|---|
| `src/` | Shared Python package skeleton for future validated toolbox components |

## Boundary

- Project-local scripts stay inside `Projects/`.
- Move code here only after a project produces reusable evidence.
- Do not promote speculative abstractions into the shared toolbox.
